Bulk Accreditation Upload

Import accreditation records and attach certificate files to the correct RRT learner without leaving the Academy workspace.

1. Download TemplateEnter the learner, accreditation details and exact certificate file name.
2. Upload SpreadsheetRRTA matches each row to an existing RRT learner by employee number or email.
3. Upload CertificatesChoose certificate files together and RRTA matches them by file name.

Spreadsheet

Upload Excel or CSV
Required: Employee Number or Email Address and Accreditation Name. One spreadsheet is processed at a time.

Certificate Files

Select Certificates
Select multiple PDF, JPG or PNG certificates in one batch. The certificate filename must match the filename entered in the spreadsheet.
Files per batchNo fixed page limit in RRTA; select multiple files together. For reliability, use manageable batches.
Maximum file size20 MB per certificate file.
Accepted formatsPDF, JPG and PNG.
Matching ruleFilename must exactly match the Certificate Filename column (case is ignored).

Review & Match

Nothing is saved until you press Import Accreditations. Check every row is marked Ready before importing.
